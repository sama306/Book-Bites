# 📚 Books Bites

Books Bites es una aplicación web desarrollada con Astro que permite explorar libros de forma rápida e intuitiva.

## 🚀 Demo

https://booksbites.netlify.app/

## ✨ Características

- Exploración de libros
- Diseño responsive
- Interfaz moderna
- Optimización de rendimiento con Astro

## 🛠️ Tecnologías

- Astro
- JavaScript
- HTML5
- CSS3
